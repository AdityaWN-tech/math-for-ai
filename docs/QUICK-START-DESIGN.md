# Quick Start — Figma in 30 Minutes

Do this before writing app code.

## 1. Duplicate these four files (10 min)

Open each link → **Duplicate to your drafts** → Move to team project `Math for AI`:

| # | File | Link |
|---|------|------|
| 1 | E-Tutor LMS | https://www.figma.com/community/file/1271304360859402063/e-tutor-learning-management-system-community |
| 2 | Code Editor Learning Platform | https://www.figma.com/design/ombLNHqde0OB66uIesz7Ay/Code-Editor-Learning-Platform-UI--Community- |
| 3 | Learning Skills Platform | https://www.figma.com/community/file/1511080132826644065/learning-skills-platform |
| 4 | Coursiva.io kit | Search “Coursiva.io” in https://www.figma.com/community/website-templates/e-learning |

Optional landing: [SkillQue](https://www.figma.com/community/file/1643119431001316704/skillque-ui-ux-figma-landing-page-copy) or [LearnPro](https://www.figma.com/community/file/1512394369372185201/learnpro-career-acceleration-website-ui-kit)

## 2. Create product file (5 min)

New file: **`Math for AI — Product`**

Pages:
- `00 Tokens`
- `01 Components`
- `02 Marketing`
- `03 App`
- `04 Prototype`

## 3. Paste tokens (5 min)

From `design/tokens.css` — create Figma color styles:
- `blueprint` #3553ff
- `paper` #fafaf5
- `ink` #1a1a1a
- `surface` #f3f1e8

Text styles: VT323 24/32 display, Source Serif 4 16/24 body, JetBrains 14/20 code.

## 4. Compose Learning Shell (10 min)

Follow [WIREFRAME-MAP.md](WIREFRAME-MAP.md):

1. Copy **Code Editor** main frame → `03 App`
2. Add left column (240px) — paste **Coursiva** step card
3. Add right column (320px) — rectangle “Output + Deploy”
4. Copy **E-Tutor** header → add breadcrumb `Phase 1 · Lesson 01`
5. Add bottom bar: Back | Hint | Run | Continue

## 5. Prototype one flow

Link: Landing (SkillQue hero) → Sign up → Dashboard (Learning Skills) → Shell

Publish prototype link → share for feedback.
